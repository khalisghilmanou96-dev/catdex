# CatDex — correction bouton Au hasard v3

Le bouton **Au hasard** :
1. réinitialise la recherche ;
2. restaure systématiquement la grille complète des races en arrière-plan ;
3. ouvre ensuite uniquement la fiche aléatoire en modale.

Ainsi, même si une recherche ou un état précédent avait réduit la grille, l'arrière-plan revient toujours à l'accueil complet avant l'ouverture de la fiche.

Version statique GitHub Pages, sans clé API.
